# 🧠 Smoker Detection using Bio-signals
This project addresses the binary classification task of identifying individuals as smokers or non-smokers based on routine health examination data. By integrating domain knowledge from biomedical sciences with machine learning and model interpretability tools, the goal is to uncover physiological markers most indicative of smoking behavior.

### Project scripts

- `src/training_pipeline.py` — the training entrypoint. It loads training data from `data/train/train.csv`, runs preprocessing (`src/utils.preprocess_data` with `mode='train'`), which computes derived features (BMI, WHtR, eyesight), scales with a `QuantileTransformer`, and uses RFECV (DecisionTreeClassifier estimator) to select the top features. Training uses a balanced RandomForestClassifier (configured in the script) and saves the trained model to `models/balanced_RFC.joblib`.

- `src/inference.py` — loads test data from `data/test/test.csv`, preprocesses it with `mode='inference'` to apply the fitted `quantile_transformer`, feature selector and the `input_features` ordering, then loads either `models/logistic_regression.joblib` or `models/balanced_RFC.joblib` and prints 'Smoker' / 'Non-Smoker' based on the model prediction.

- `src/utils.py` — helpers for path assertions, data loading, split, preprocessing (train/inference modes), save/load joblib models, RFECV/feature helpers, and simple train/test wrappers which compute metrics. The module exposes `preprocess_data(..., mode='train'|'inference')` which is central to consistent feature handling across training and inference.

### Preprocessing specifics

- Derived features computed in `mode='train'`:
  - `BMI` = weight(kg) / (height(m))^2
  - `WHtR` = waist(cm) / height(cm)
  - `eyesight` = eyesight(left) + eyesight(right) / 2
  - Columns removed after deriving these features: raw weight/height/waist/eyesight/hearing columns so the model only sees engineered inputs.

- For training, `QuantileTransformer` is used for robust scaling. Feature selection is applied via RFECV with a DecisionTreeClassifier estimator (10-fold stratified CV), selecting at least 15 features.

- For inference, `preprocess_data()` loads `models/quantile_transformer.joblib`, `models/RFECV_fitted.joblib`, and `models/input_features.joblib` to ensure the same transform & feature ordering are applied.

### Models & artifacts

- Models saved in `models/` (examples in this repository):
  - `balanced_RFC.joblib` — RandomForestClassifier trained with class-balanced settings (saved by `training_pipeline.py`).
  - `logistic_regression.joblib` — logistic regression baseline (if present).
  - `quantile_transformer.joblib` — fitted QuantileTransformer used for scaling.
  - `RFECV_fitted.joblib` — fitted RFECV selector used to transform inputs to selected features.
  - `input_features.joblib` — ordered list of input features expected by the model.

### Training & evaluation flow

- After preprocessing and feature selection, the RandomForestClassifier in `training_pipeline.py` is trained with hyperparameters optimized for class balance (n_estimators=160, max_depth=10, etc.) and returned via `utils.train_model()`.

- `training_pipeline.py` saves the trained model to `models/balanced_RFC.joblib` and then calls `utils.test_model(..., metric='f1_score')` to compute an F1 score on the validation split.

### Reports and performance artifacts

Reports generated by notebooks and evaluation scripts live in `reports/`. Key files include:

- `Confusion_Matrices.png` — confusion matrices for evaluated models.
- `ROC_Curves.png` — ROC curves comparing models (useful for threshold selection and AUC).
- `Precision_Recall_Curves.png` — precision-recall curves for models.
- `RandomForestClassifier_SHAP_Analysis.png`, `LogReg_SHAP_Analysis.png`, `DecisionTreeClassifier_SHAP_Analysis.png` — SHAP visualizations showing feature impacts for each model.
- `feature_histograms.png`, `feature_boxplots.png` — feature distributions and boxplots used during EDA.
- `decision_tree_classifier_visualization.png` — tree structure visualization (DecisionTreeClassifier) used for interpretability.

### How to reproduce locally

```powershell
# 1) create environment (conda recommended)
conda env create -f environment.yml
conda activate smoker-detection

# 2) train (reads data/train/train.csv)
python src/training_pipeline.py

# 3) run inference on test set (reads data/test/test.csv)
python src/inference.py

# 4) open reports/ to view saved figures (ROC, PR curves, SHAP plots, confusion matrices)
```

- Class imbalance: training uses `class_weight='balanced'` in the RFC and RFECV is stratified to account for class ratios. Consider additional sampling strategies (SMOTE, class-specific sampling) if recall on smokers needs improvement.
